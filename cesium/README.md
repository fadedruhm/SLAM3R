# Cesium GLB 手动摆放工具

## 项目简介

本目录提供一个用于数字地球场景的模型摆放页面：

- 页面文件：index.html
- 目标：在 Cesium 地球中手动放置 GLB 模型，并实时调整位置、角度和大小
- 适用场景：SLAM3R 重建模型快速落地、人工微调、结果复现

当前页面已支持：

- 加载 GLB 或 GLTF 模型（支持 URI 和本地文件）
- 选择本地文件时自动复制到 `cesium/models/` 子目录
- 调整经度、纬度、高度
- 调整 Heading、Pitch、Roll
- 调整缩放比例
- 显示或隐藏模型坐标轴（X 红 / Y 绿 / Z 蓝）
- 点击地图放置模型锚点
- 保存、导出、导入摆放参数

## 如何启动

推荐使用本目录提供的启动脚本，避免直接双击 HTML 带来的资源访问限制。

### 方式一：使用项目内置服务（推荐）

1. 打开终端并进入仓库根目录。
2. 运行：

```powershell
python cesium/server.py
```

3. 浏览器访问：

- http://127.0.0.1:8000/cesium/index.html

### 方式二：继续使用 `python -m http.server`（仅限 URI 模型）

1. 打开终端进入 cesium 目录。
2. 运行：

```powershell
python -m http.server 8000
```

3. 浏览器访问：

- http://127.0.0.1:8000/index.html

注意：该方式不支持“本地 GLB 自动复制到 `cesium/models/`”，因为它没有上传 API。

## 快速使用步骤

1. 在 模型 URI 中填写模型路径，或选择本地 GLB 文件。
2. 如果选择本地 GLB，系统会自动上传并复制一份到 `cesium/models/`，并把返回的固定路径填入模型 URI。
2. 点击 加载/重载模型。
3. 调整位置参数（经纬高）和姿态参数（Heading、Pitch、Roll）。
4. 如需快速定位，可点击 点击地图放置 或 使用当前视角中心。
5. 需要检查朝向时，打开 显示坐标轴 并设置轴长度。
6. 调整完成后，可：
   - 保存到本地缓存
   - 导出配置 JSON（便于共享和复现）
   - 导入配置 JSON（恢复已有摆放结果）

保存缓存和导出 JSON 时，会保存每个模型的 `modelPath`（例如 `/cesium/models/xxx.glb`）。
重新读取缓存或导入 JSON 时，会直接按该路径重新加载模型。

## 底图与稳定性说明

页面默认禁用了 Cesium 默认底图流程，改为手动加载 ArcGIS World Imagery。

这样可以避免：

- 默认底图在未配置专属 Token 时出现 401 Unauthorized
- 普通 OSM 在极低空缩放时因切片层级上限导致的蓝海丢图现象

## 常见问题

### 模型加载失败

- 检查模型路径是否可访问（相对路径是否正确）
- 确认通过 HTTP 服务访问页面，而不是 file 协议
- 检查浏览器控制台是否有跨域或 404 错误

### 点击地图放置无效

- 调整相机角度后重试
- 在部分视角下拾取不到有效地面点，切换到更俯视的视角通常更稳定

### 导出后无法复现

- 确认导入的是同一模型
- 检查单位和缩放是否一致
- 建议在同一底图与同一版本页面中复现
